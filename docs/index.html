Library management for Serato DJSerato DJ 曲庫管理工具

Cratify screens new music, sorts songs into crates, cleans up duplicates and missing files, and checks audio quality. Changes are written to Serato only when you apply them, after a test run on a copy and a backup. Cratify 提供新歌篩選、crate 分類、重複與遺失檔案清理，以及音質檢查。所有變更須經套用才會寫入 Serato，寫入前會先在複本上測試並備份。

Folder status資料夾狀態

Each file in the music folders is labelled sorted, unsorted, not imported, copy, rejected or missing, with totals per folder.音樂資料夾中的每個檔案都會標示為已分類、未分類、未匯入、副本、已淘汰或遺失，並依資料夾統計。

The audio format is read from each file, so AAC and ALAC in .m4a files are told apart.音訊格式直接讀取自檔案，可區分 .m4a 內的 AAC 與 ALAC。

Transcode check轉檔檢查

Lossy encoders remove high frequencies, and conversion cannot restore them. Cratify measures where the sound stops in each file and flags files whose cut-off is below what their format allows, such as an MP3 320 made from a 128k file.有損編碼會切除高頻，轉檔後無法還原。Cratify 測量每個檔案的聲音截止頻率，並標示低於該格式應有範圍的檔案，例如由 128k 轉成的 MP3 320。

The check runs on request at background priority. Results are kept, so later runs check only new or changed files.檢查需手動啟動，以背景優先權執行；結果會保留，之後只檢查新增或變更的檔案。

Safety資料安全

Cratify works on a copy of the Serato database, so Serato can stay open while you use it. Only "Apply to Serato" writes to the database, and only while Serato is closed.Cratify 讀取的是 Serato 資料庫的複本，使用期間 Serato 可以保持開啟。只有「套用到 Serato」會寫入資料庫，且須在 Serato 結束後執行。

  • Both database files are written in one transaction. If any check fails, nothing is written.兩個資料庫檔案在同一筆交易中寫入，任一項檢查未通過即不寫入。
  • The database is backed up before each apply and can be restored from Plan.每次套用前自動備份，可在「變更計畫」還原。
  • Writing is supported only for database version 202 (Serato DJ Pro 4.0).僅支援寫入資料庫版本 202（Serato DJ Pro 4.0）。

Other features其他功能

CratesCrate 結構

Rename, move, merge, delete and reorder crates.重新命名、移動、合併、刪除 crate 及調整順序。

Duplicates重複曲目

Matched by artist and title. The copy with the best quality is preselected.依歌手與歌名比對，預設保留音質最佳的版本。

Missing files遺失的檔案

Relocate to a file with the same name, or merge into an existing record.重新指定為同名檔案，或合併到現有記錄。

Add to Serato加入 Serato

Add songs from Folders in the same way as Serato's import.從「資料夾」將歌曲加入 Serato，方式與 Serato 匯入相同。

Notes筆記

Notes on songs, with #tags and Markdown export. Stored in Cratify only.歌曲筆記，支援 #標籤與 Markdown 匯出，僅儲存於 Cratify。

Languages介面語言

English and Traditional Chinese.英文與繁體中文。

Install安裝

System requirements系統需求

  • macOS12 or later, Apple silicon12 以上，Apple 晶片
  • Serato DJ Pro4.0
  • PythonIncluded in the app已內建於 app
  • ffmpegOptional, for the transcode check選用，轉檔檢查需要
  • License授權MIT

Steps步驟

  1. Download Cratify-0.1.1-mac-arm64.zip from GitHub Releases, unzip it and move Cratify.app to Applications.從 GitHub Releases 下載 Cratify-0.1.1-mac-arm64.zip，解壓縮後將 Cratify.app 移到「應用程式」。

  2. The app is not signed by Apple yet. On first launch, choose Open Anyway in System Settings → Privacy & Security, or run:本 app 尚未經 Apple 簽署。首次啟動時，請至「系統設定」→「隱私權與安全性」按「強制打開」，或執行：

    xattr -dr com.apple.quarantine /Applications/Cratify.app

  3. Optional, for the transcode check:選用（轉檔檢查需要）：

    brew install ffmpeg
